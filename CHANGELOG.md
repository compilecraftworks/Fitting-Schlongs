# Changelog

## 1.0.4

- Updated the build dependency to the stable alandtse/CommonLibSSE-NG 6.7.0
  tag and pinned its exact commit as a Git submodule.
- Documented stable XMake 3.1.0 with its exact tag commit and official bundle
  checksum for reproducible release builds.
- Completed a clean SE/AE release build with XMake 3.1.0 and the pinned
  CommonLibSSE-NG 6.7.0 build closure.
- Updated dependency provenance and licensing notices for CommonLibSSE-NG's
  GPL-3.0-or-later license, Modding Exception, and GPL-3.0 Linking Exception.
- No Fitting Schlongs classification or runtime behavior was changed.

## 1.0.3

- Slot 32 full-body armor now retains default SOS/TNG covering behavior.
- Conflicting revealing keywords are removed without adding underwear or
  concealing keywords to otherwise ordinary slot 32 armor.
- Runtime classifier results remain final when ESP or KID rules provide the
  opposite SOS/TNG keyword.

## 1.0.2

- Made recognized slot 32/49 classifier results override conflicting SOS/TNG
  keywords.
- Expanded English, Korean, and Simplified Chinese outfit-name classification.

## 1.0.1

- Improved SOS/TNG genital-armor detection and slot 52 filtering.
- Excluded TNG GenitalCover and unrelated slot 52 equipment.

## 1.0.0

- Initial standalone release.
